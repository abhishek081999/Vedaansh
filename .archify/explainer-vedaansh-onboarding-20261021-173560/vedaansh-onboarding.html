Answer

Vedaansh calculates Vedic charts with Swiss Ephemeris, then gates paid features from MongoDB — not from the JWT alone.

  1. The browser hits proxy.ts, then App Router pages and Node API routes.
  2. calculateChart in src/lib/engine stays pure: no React, Mongo, Redis, or NextAuth imports.
  3. Effective plan is free|gold|platinum via getEffectivePlan() and requirePlanGate().
  4. Razorpay checkout writes User.plan and planExpiresAt; expiry silently returns free.
